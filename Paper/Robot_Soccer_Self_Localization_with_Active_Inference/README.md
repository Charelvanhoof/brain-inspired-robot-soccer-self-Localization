# Overleaf Paper Scaffold

This folder is an Overleaf-ready LaTeX scaffold for the robot-soccer self-localization paper.

## Files

- `main.tex`: main LNCS/CCIS paper entry point.
- `sections/*.tex`: section drafts following `paper_preparation.MD`.
- `references.bib`: seed bibliography from `citation_notes/`.
- `figures/`: place exported diagrams and result plots here.

## Overleaf Setup

Use a Springer LNCS/CCIS Overleaf project or upload this folder into a project that contains the Springer `llncs.cls` class and `splncs04.bst` bibliography style.

For double-blind review, keep the anonymous author block in `main.tex` until the paper is accepted or the venue requests author details.
